# Electrochemistry Equation Atlas

Open **index.html** in a modern browser. The program is a single self-contained HTML file: no installation, server, dependencies, or internet connection needed.

- Search equations and their explanations or filter by topic.
- Select an equation for parameters, implications, assumptions, and an example.
- Copy or print the selected entry.
- Adjust the Nernst calculator inputs to explore equilibrium potential.
- Bookmark an entry using the URL fragment.

External source links open online references; they are not needed to use the program. Equations use the conventions stated in each entry. This is an educational reference, with idealizations and limitations included alongside each relationship.
